# Valid9 Homebrew tap

Homebrew packages for [Valid9](https://www.valid9.com) customer tools.

The first `v9` cask (the Valid9 customer CLI) is being prepared. It will be added here after its signed
Mac downloads have been published and tested. There is no installable cask yet.

The planned command, **after the first release**, is:

```sh
brew install --cask valid9d/tap/v9
```

The tap downloads versioned customer binaries from
[valid9d/v9cli](https://github.com/valid9d/v9cli/releases) and verifies their
SHA-256 checksums. Mac binaries will be signed and notarized. Installing the
CLI does not grant access to any organization; sign in with your Valid9 account.

[CLI guide](https://www.valid9.com/docs/cli/) · hello@valid9.com

## Maintaining the tap

Each package update arrives as a pull request with the cask generated by the
private CLI release workflow. Publish the corresponding binary release before
merging the cask. Check its URLs and checksums, run Homebrew's cask checks, and
test installation, `v9 --version`, upgrade and uninstall on supported Macs.
Never modify an archive after its version has been published.
